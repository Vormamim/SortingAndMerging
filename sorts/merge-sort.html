Merge Sort

A divide and conquer algorithm: split the array in half recursively until each piece has one element (already sorted by definition), then merge sorted halves back together in order. Unlike the other three algorithms, it needs extra memory for the sub-arrays and always runs in O(n log n) time, regardless of the starting order.

Variables & data structures

  • arr — the array (or sub-array) currently being sorted.
  • mid — the midpoint index used to split arr into two halves.
  • left, right — auxiliary arrays holding the two halves. This is the key structural difference from the other three sorts: merge sort is not purely in-place, it needs O(n) extra array space.
  • i, j — read positions inside left and right during a merge.
  • k — write position back into arr during a merge.

Control structures

  • Selection (base case): IF len(arr) > 1 decides whether to keep dividing or stop.
  • Recursion: merge_sort() calls itself on the left half, then the right half — this replaces the loop-based iteration used by the other three algorithms.
  • Iteration: inside merge(), a WHILE loop interleaves left and right by comparison, followed by two clean-up WHILE loops that copy across whatever is left over.

Pseudocode & Python code

Pseudocode

BEGIN MergeSort(arr)
  IF length(arr) > 1 THEN
    mid ← length(arr) DIV 2
    left ← arr[0 .. mid-1]
    right ← arr[mid .. length(arr)-1]
    MergeSort(left)
    MergeSort(right)
    Merge(arr, left, right)
  END IF
END MergeSort

BEGIN Merge(arr, left, right)
  i ← 0 ; j ← 0 ; k ← 0
  WHILE i < length(left) AND j < length(right) DO
    IF left[i] ≤ right[j] THEN
      arr[k] ← left[i] ; i ← i + 1
    ELSE
      arr[k] ← right[j] ; j ← j + 1
    END IF
    k ← k + 1
  END WHILE
  WHILE i < length(left) DO
    arr[k] ← left[i] ; i ← i + 1 ; k ← k + 1
  END WHILE
  WHILE j < length(right) DO
    arr[k] ← right[j] ; j ← j + 1 ; k ← k + 1
  END WHILE
END Merge

Python

def merge_sort(arr):
    if len(arr) > 1:
        mid = len(arr) // 2
        left = arr[:mid]
        right = arr[mid:]

        merge_sort(left)
        merge_sort(right)
        merge(arr, left, right)
    return arr


def merge(arr, left, right):
    i = j = k = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            arr[k] = left[i]
            i += 1
        else:
            arr[k] = right[j]
            j += 1
        k += 1
    while i < len(left):
        arr[k] = left[i]
        i += 1
        k += 1
    while j < len(right):
        arr[k] = right[j]
        j += 1
        k += 1
