Selection Sort

On each pass, scans the unsorted part of the array to find the smallest remaining value, then swaps it into place at the front of the unsorted section. Unlike Bubble Sort, each pass makes at most one swap.

Variables & data structure

  • arr — the array being sorted (fixed-size, in place).
  • n — number of elements in arr.
  • i — outer loop counter: the position we're about to fill.
  • j — inner loop counter: scans the unsorted section.
  • min_index — index of the smallest value found so far in the current pass.

Control structures

  • Nested iteration: an outer FOR loop (one per final position) containing an inner FOR loop (search for the minimum).
  • Selection: an IF inside the inner loop updates min_index whenever a smaller value is found.
  • Selection: an IF after the inner loop only swaps if the minimum wasn't already in place.

Pseudocode & Python code

Pseudocode

BEGIN SelectionSort(arr, n)
  FOR i ← 0 TO n - 2 DO
    min_index ← i
    FOR j ← i + 1 TO n - 1 DO
      IF arr[j] < arr[min_index] THEN
        min_index ← j
      END IF
    END FOR
    IF min_index ≠ i THEN
      swap(arr[i], arr[min_index])
    END IF
  END FOR
END SelectionSort

Python

def selection_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        min_index = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_index]:
                min_index = j
        if min_index != i:
            arr[i], arr[min_index] = arr[min_index], arr[i]
    return arr
