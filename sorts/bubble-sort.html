Bubble Sort

Repeatedly steps through the array, comparing each pair of adjacent elements and swapping them if they're in the wrong order. Larger values "bubble up" to the end with each pass. Stops early once a whole pass makes no swaps.

Variables & data structure

  • arr — the array being sorted (fixed-size, in place — no extra array needed).
  • n — number of elements in arr.
  • i — outer loop counter: which pass we're on.
  • j — inner loop counter: which adjacent pair is being compared.
  • swapped — boolean flag; lets the algorithm exit early if a pass makes no swaps.

Control structures

  • Nested iteration (selection by counting): an outer FOR loop (passes) containing an inner FOR loop (comparisons).
  • Selection: an IF statement decides whether to swap each pair.
  • Selection (early exit): an IF NOT swapped THEN break out of the outer loop once the array is sorted.

Pseudocode & Python code

Pseudocode

BEGIN BubbleSort(arr, n)
  FOR i ← 0 TO n - 2 DO
    swapped ← False
    FOR j ← 0 TO n - 2 - i DO
      IF arr[j] > arr[j + 1] THEN
        swap(arr[j], arr[j + 1])
        swapped ← True
      END IF
    END FOR
    IF swapped = False THEN
      BREAK          { already sorted, stop early }
    END IF
  END FOR
END BubbleSort

Python

def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr
