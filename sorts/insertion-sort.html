Insertion Sort

Builds up a sorted section at the front of the array one element at a time. Each new element (the key) is shifted left past every larger element in the sorted section until it reaches its correct position — the way most people sort a hand of playing cards.

Variables & data structure

  • arr — the array being sorted (fixed-size, in place).
  • n — number of elements in arr.
  • i — index of the next element to insert into the sorted section arr[0..i-1].
  • key — the value being inserted (a copy of arr[i]).
  • j — scans backwards through the sorted section looking for key's position.

Control structures

  • Iteration: an outer FOR loop, one iteration per element to insert.
  • Iteration (condition-controlled): an inner WHILE loop that keeps shifting while j ≥ 0 and arr[j] > key — a compound condition combining a bounds check with a value check.
  • Sequence: the shift (arr[j+1] ← arr[j]) and the final insert (arr[j+1] ← key) always run in the same order.

Pseudocode & Python code

Pseudocode

BEGIN InsertionSort(arr, n)
  FOR i ← 1 TO n - 1 DO
    key ← arr[i]
    j ← i - 1
    WHILE j ≥ 0 AND arr[j] > key DO
      arr[j + 1] ← arr[j]
      j ← j - 1
    END WHILE
    arr[j + 1] ← key
  END FOR
END InsertionSort

Python

def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr
