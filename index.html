Sorting algorithms

Each page identifies the variables and control structures used, gives a flowchart and matching pseudocode, provides the Python code, and lets you desk-check the algorithm on any array you like.

O(n²)

Bubble Sort

Repeatedly compares and swaps adjacent elements until no swaps are needed.

 O(n²)

Selection Sort

Repeatedly selects the smallest remaining value and swaps it into place.

 O(n²)

Insertion Sort

Grows a sorted section at the front of the array, one key at a time.

 O(n log n)

Merge Sort

Divides the array in half recursively, then merges sorted halves back together.

How to use this site

  1. Read the theory section for the data structure or algorithm.
  2. Check the variables and control structures panel — know what each one is doing before you trace it.
  3. Step through the flowchart and pseudocode side by side.
  4. Use the interactive desk check: type your own array (or randomise one), then click Next repeatedly and watch the trace table fill in — that's exactly what you'd write by hand on paper.
  5. Compare against the Python code to see the working implementation.
